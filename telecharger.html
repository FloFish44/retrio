Votre téléchargement commence.

Il ne reste que quelques étapes pour utiliser Retrio sur votre ordinateur.

  1. 1Ouvrez le fichier téléchargéCliquez sur Installateur_Retrio.exe dans vos téléchargements.
  2. 2Autorisez l’installationSi Windows demande une confirmation, vérifiez que le fichier vient bien de retrio.eu, puis cliquez sur « Oui ». Si l’écran « Windows a protégé votre ordinateur » apparaît, cliquez sur « Informations complémentaires », puis « Exécuter quand même ».
  3. 3Installez et ouvrez RetrioSuivez les quelques étapes affichées par l’installateur. Retrio peut ensuite être utilisé gratuitement.
Vous avez Retrio Pro ?
Dans Retrio, ouvrez la rubrique Pro et saisissez exactement la même adresse e-mail que celle utilisée lors du paiement. Aucun code n’est nécessaire : vos fonctionnalités Pro seront activées automatiquement.
